## 内容

Na・K・Ca・Mg・Pの電解質異常9症例を収載。各症例で以下の4つの問いに自分の言葉で答えてから模範解答を確認する形式です。

1. 本当に緊急か
2. 原因検索より先に治療が必要か
3. どの薬剤を止めるか
4. どの速度で補正するか

ゴールは診断名を当てることではなく、危険な電解質異常を見抜き初動を間違えないことです。各症例に「ありがちな誤対応」を明示し、模範解答とあわせて自己評価・進捗記録（ブラウザのlocalStorage）ができます。

## 症例一覧

- ナトリウム異常: 高Na血症(高齢者脱水) / 重症低Na血症(多飲) / SIADH
- カリウム・マグネシウム異常: 高K血症(CKD) / 低K+低Mg血症・QT延長(甲状腺中毒性周期性四肢麻痺) / 低Mg血症(PPI+利尿薬)
- カルシウム異常・複合病態: 高Ca血症(悪性腫瘍) / 術後低Ca血症 / リフィーディング症候群

## 使い方

`index.html` をブラウザで開くだけで動作します（外部依存はGoogle Fontsの読み込みのみ）。

## 免責事項

内容は教育目的の一般的な整理です。実際の治療方針は必ず各施設のプロトコルや指導医の判断、最新のガイドラインに従ってください。

## GitHub Pagesの有効化

このリポジトリをGitHubに公開（Publish）した後、以下の手順で `index.html` をWeb公開できます。

1. GitHub上でこのリポジトリを開く
2. **Settings → Pages** を開く
3. 「Build and deployment」の **Source** を `Deploy from a branch` にする
4. **Branch** を `main` / `/ (root)` にして **Save**
5. 数分待つと、ページ上部に公開URL（`https://namazu1995-coder.github.io/electrolyte-training/`）が表示されます

有効化すると、上記のQRコード・URLがそのまま使えるようになります。
